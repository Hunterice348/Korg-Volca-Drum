# V-DRUM LAB

## Advanced Digital Percussion Synthesizer VST3

Профессиональный виртуальный цифровой перкуссионный синтезатор, основанный на архитектуре Korg Volca Drum.

### Особенности

- 6 независимых Drum Parts с 2 слоями каждая
- Полноценный DSP-синтез (не сэмплер)
- Waveguide Resonator с режимами Tube/String
- 16-шаговый секвенсор с Motion Sequencing
- Профессиональный industrial-дизайн

### Системные требования

- Windows 10/11 (x64)
- VST3-совместимая DAW (FL Studio, Ableton Live, Cubase, Reaper, Studio One)

### Сборка

#### Требования

- CMake 3.15+
- Visual Studio 2019/2022
- JUCE 7.x
